# 🚀 Personal Portfolio Website

A modern, interactive personal portfolio built with **React** and **Next.js**, designed to showcase my projects, skills, and professional journey. The focus of this project is to deliver a smooth user experience, strong UI/UX design, and efficient functionality.

---

## ✨ Key Features

### 🎨 Interactive & Modern UI
- Built using **React components**
- Smooth animations and transitions
- Clean, responsive, and user-friendly design

### 📂 Project Showcase
- Displays selected projects with:
  - Descriptions
  - Technologies used
  - Live/demo links

### 👨‍💻 About & Skills
- Highlights my experience in:
  - Machine Learning & AI
  - Computer Vision
  - Web & Mobile Development

### 📬 Contact Form with Email Automation
- Fully functional contact form
- Automatically sends messages to my email
- Integrated email automation (no manual handling required)

### ⚡ Performance Optimized
- Built with **Next.js App Router**
- Optimized rendering, routing, and font loading

### 📱 Fully Responsive
- Works across mobile, tablet, and desktop devices

## 🚀 Getting Started (Run Locally)

### 1. Clone the repository
```bash
git clone https://github.com/Elin-powS/Swopnile-s-Portfolio.git
cd Swopnile-s-Portfolio
```
### 2. Install dependencies
```bash
npm install
# or
yarn install
# or
pnpm install
```
### 3. Run the development server
```bash
npm run dev
```
### 4. Open in browser
```bash
http://localhost:3000
```
### ⚙️ Environment Variables
Create a .env.local file in the root directory:
```bash
EMAIL_USER=your-email@example.com
EMAIL_PASS=your-email-password
EMAIL_RECEIVER=your-receiving-email@example.com
```
## 🌐 Deployment

### Deploy on Vercel

1. Push your code to GitHub  
2. Go to [Vercel](https://vercel.com/new)  
3. Import your repository  
4. Add environment variables (if needed)  
5. Click **Deploy**

Vercel will automatically build and host your Next.js app.
